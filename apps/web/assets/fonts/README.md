# Bundled workspace fonts

Inter Variable and Noto Sans SC Variable, Fontsource version 5.3.0.
Sources: https://fontsource.org/fonts/inter and https://fontsource.org/fonts/noto-sans-sc.
Downloaded from the official npm registry packages @fontsource-variable/inter and @fontsource-variable/noto-sans-sc.

Original WOFF2 subsets and unicode ranges are preserved. Browsers fetch only the subsets needed by visible text. No external font service is contacted. Both fonts use the SIL Open Font License; see the accompanying OFL files. Total packaged font assets are approximately 4.85 MB.
