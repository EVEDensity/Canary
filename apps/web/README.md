# Canary verification workspace

The report application displays checks, architecture, coverage, source locations, failure evidence and linked rerun comparisons.

Data comes from recorded runs through HTTP APIs and live updates. The interface preserves incomplete and unavailable states; it does not change verification results.

Write operations require the operator token supplied by the CLI. Keep the server on loopback and review exported evidence before sharing.

See [workspace guide](../../docs/guides/unified-workspace.md), [architecture map](../../docs/guides/architecture-map.md) and [security policy](../../SECURITY.md).
