# 界面语言与翻译

工作台支持英语与简体中文。页面语言菜单记忆用户选择，也支持 `?lang=en` 和 `?lang=zh-CN`。切换时保留运行、地图视角、筛选与验证状态。

源码、日志、堆栈、检查标识及用户输入保持原文；日期按界面语言与浏览器时区显示。

## 新增语言

翻译资源位于 `apps/web/locales/`，资源必须具有一致的消息键与占位符。

```bash
pnpm i18n:add fr
pnpm i18n:check
```

补齐译文并提交 PR。维护者审核术语、占位符、操作含义和布局后合并；完整资源自动进入语言菜单，未完成草稿不会展示。相关工作流自动校验资源。

## 开发约定

使用 `t('消息键')` 和 `tfmt('含 {count} 的消息键', { count })`，同步更新正式语言资源。内置诊断与服务端说明同样需要登记；原始错误和用户数据不进入翻译函数。

图表、下拉框与动态提示的缓存应包含语言标识，避免切换后保留旧文案。
