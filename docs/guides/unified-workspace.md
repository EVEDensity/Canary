# 统一验证工作台

原项目页面负责命令检查、状态、日志、重跑与报告；原 Agent 页面负责用例、断言、轨迹、覆盖率和改进建议。现在两个入口共用一个工作台，在同一个端口浏览当前项目的两类运行。

## 信息与交互

- 左侧：固定功能导航；顶部选择当前运行。运行历史提供最近 100 次记录、类型筛选与 ID 搜索。
- 数据总览：指标卡、同类型检查通过率趋势、当前结果环图、耗时排行与覆盖率条形图。历史窗口支持最近 12 / 24 / 50 次，点击趋势点切换运行。
- 检查与日志：执行详情、脱敏输出和重跑操作。
- 覆盖率：行、语句、函数、分支、文件精度和功能链；项目检查直接展示关联 Agent 子运行的数据。
- 用例与轨迹：断言、执行指标和按需加载的轨迹；项目记录可进入子运行。
- 证据与比较：完整性、manifest、源码及配置哈希、来源运行和同类型历史比较。
- 改进建议：保留接受、拒绝、验证操作；导出 JSON、Markdown、JUnit。

视觉采用用户确认的暖白、石墨与珊瑚橙。主趋势和右侧关注区占据首屏，下方安排耗时、覆盖范围和结果。趋势支持通过率 / 耗时切换、悬停与键盘聚焦读数；点击耗时条目打开详情抽屉。窄屏按信息优先级改为单列，并尊重减少动态效果的系统偏好。设计参考和验收见[设计记录](../evidence/studio-redesign-record.md)。

趋势按开始时间排列，只比较同类型、已结束的运行（含失败和中断），分母为各自计划项。重试子集标记 R；不把不同计划的点连线解释为同范围质量改善。结果环图中的其余项包括待执行或不适用项，100% 计划项通过不替代覆盖率门禁 verdict。

## 数据边界

页面不生成模拟指标。未采集的覆盖率明确显示“尚未采集”；重试子集不会借用原运行的数据。多组覆盖率分别展示，不平均不同分母的百分比。现有 Agent 源码覆盖率只代表其配置范围，不能代表整个仓库；近似或不可用的映射保留质量标记。

历史摘要按需读取并缓存，选中运行后校验完整性。关联子运行必须位于当前项目仓库，且 manifest 与父记录一致。工作台每 4 秒刷新紧凑数据，隐藏页面暂停轮询；轨迹按需加载。旧报告和 SSE API 继续保留。

## 启动

```sh
canary run --port 4318
```

默认配置选择规则保持不变。显式使用 Agent 配置时也打开同一界面；可用操作取决于该会话提供的重跑、重放和关闭能力。
