# 项目架构地图

运行 `canary run --port 4318` 后，首页“从架构进入问题现场”卡片显示当前运行的模块、文件和符号数量。点击“探索项目地图”进入同一页面的地图工作区；也可使用左侧“项目结构”。地图读取该运行封存的 `structure.json`，只在 manifest 完整性校验通过后显示。旧运行没有结构快照或证据损坏时会明确提示，不使用当前源码补画。

## 浏览与定位

- 二维结构默认展示当前节点与直接子节点。单击节点查看详情，双击或点击“进入下一级”展开；面包屑返回上层。左侧树可以展开、折叠或直接选择任意节点。
- 搜索按名称、项目内相对路径和符号名匹配；点击结果可直接聚焦到该节点。方向键在可见节点之间移动，右方向键进入、左方向键返回；`Home`/`End` 定位首尾，`Enter` 进入选中层级。
- “范围”切到“选中模块及上下游”只绘制该节点与已确认的一跳上下游。依赖过滤可选模块导入、包依赖、函数调用或隐藏依赖。二维视图最多绘制 48 个直接子节点和 24 条同屏依赖线；其余节点可通过树或搜索访问。
- “三维分层”以 `canary.architecture.json` 的用户层为优先分组；未配置的节点按结构类型分组。倾角可以调整，随时切回二维视图查看精确连线。三维最多展示当前视窗的 32 个节点，较大的层需回到二维或树继续定位。
- 视角、聚焦节点、所选节点、搜索、关系过滤、范围和展开状态按运行保存在浏览器会话中；切换运行使用各自状态。

## 详情与证据

详情显示节点类型、项目内路径、采集时行号、结构职责、Git 变更、已确认的依赖方向以及关联检查。职责是从结构数量与节点类型计算出的摘要，不是 AI 对业务语义的猜测。相关检查只在运行覆盖证据通过源码哈希匹配后关联；没有证据时明确显示无法可靠关联。未解析关系单独计数，不画作确定依赖。

文件、类和函数可点击“查看源码片段”。服务端先比对当前文件的 SHA-256；若已变化，再尝试读取快照记录的 Git 提交并复核哈希。两者都不匹配时不展示源码。响应走统一脱敏路径，最多返回选中位置附近 80 行。工作树中未提交且后来改变的文件可能无法找回，页面会说明不可用。

当前细粒度地图只展示 JS/TS 函数与类；Python、Go、Rust 在页面先保留目录和文件浏览。结构数据本身的 Python AST 能力及静态关系边界见 [R10 结构指南](project-structure.md)。三维视图是 CSS 透视交互层，不表示运行时拓扑；静态调用边与真实运行观察继续按证据来源区分。

## 覆盖、分支与失败联动

在首页“覆盖范围”或“覆盖率分析”点击“地图定位”，地图会选中相应测量来源与指标，并定位到有可用测量的薄弱文件。文件明细也有“在地图查看覆盖与分支”。顶部可切换行、函数、分支指标与子运行来源；页面不把不同测试范围的分母合并。文件节点显示原测量分母，函数/类只有封存的 coverage manifest 能精确圈定范围时才显示自己的分母。

地图有三种颜色模式与固定图例：覆盖模式的橙色表示尚未走到的验证路径；失败模式的红色表示本次运行存在错误证据，紫色是相同源码版本的历史失败，绿色是原失败经关联重跑验证；变更模式的蓝色表示 Git 基线变更。颜色含义不能互换。未采集、外部黑盒、源码哈希不匹配与无法确定的映射显示为未知。父模块的数值只汇总所选来源里已测量的文件，并标出已测文件数量；部分文件未知时不把模块显示成完全已覆盖。

选择文件或函数后，详情显示覆盖分母、未覆盖分支和失败证据。点击某条分支的“定位源码”，服务端先核对封存源码哈希，再在源码片段中高亮对应行列，并注明条件为真/假、隐式 else 或其他分支类型。部分 V8 分支反推只有近似精度，页面会注明近似。失败堆栈会显示检查或用例名称、类别、源码行号及错误摘要，可继续回到原始检查证据。堆栈缺少可靠项目位置时会留在未知记录中。

**未覆盖是验证缺口；失败是已有错误证据。** 普通命令的堆栈位置即使与封存源码一致，也不能单独证明命令执行时所有字节相同。历史失败仅在该文件的封存哈希与当前选中运行一致时标在当前地图上；不同版本不会移植到当前源码。
