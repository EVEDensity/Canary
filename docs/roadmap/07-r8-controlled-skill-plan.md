# R8 受控 Skill 与软自进化实施计划

状态：**R8-00 已完成，等待从 R8-01 开始实施**。代码起点见 [R8 基线记录](../evidence/r8-baseline.md)。

## 目标与约束

R8 将真实失败、修复建议和历史比较转成可追溯的项目级经验，并通过离线回放、人工批准和显式回滚证明它是否有效。Canary 的核心检测在没有模型、宿主或经验时必须继续完整工作。

首轮只做一个真实 fixture 的最小闭环。不做自动批准、自动源码修改、常驻循环、多模型竞赛、跨项目默认共享或远端经验市场。

## 任务顺序

### R8-01：现有能力审计与冻结契约

- 盘点 `experience`、`improvement`、`control-plane`、CLI `soft-trial`、MCP proposal 和页面入口。
- 建立“已有实现 / 可复用 / 缺口 / 废弃重复能力”对照表。
- 冻结经验状态、作用域、批准和回滚语义，避免重新实现 S-03/S-04。

验收：形成代码级能力矩阵；每项 R8 后续需求都有唯一所有者和存储位置。

### R8-02：结构化经验候选

- 从项目问题分类、错误证据和修复建议生成 `proposed` 候选。
- 记录来源 run/check、证据哈希、适用工具、项目作用域、版本、限制和验证要求。
- 原始日志和任意工具输出不得直接变成可信经验指令。

验收：构建、测试、lint、覆盖率、配置和超时类问题可生成稳定 Schema；重复输入得到可解释的去重结果。

### R8-03：最小上下文选择

- 按 projectRoot、检查类型、语言/工具、case/tag/feature 和版本选择经验。
- 设置条目数与字符预算，拒绝跨项目和超预算加载。
- 在 run snapshot 与 manifest 中记录实际加载的经验 ID、版本和内容哈希。

验收：不相关经验不会进入上下文；页面和 artifact 能解释每条经验为何被加载。

### R8-04：离线回放与收益判定

- 固定 baseline、candidate、regression 和独立 holdout。
- 比较通过率、错误分类、耗时、重试、覆盖范围和可用时的 token 指标。
- 缺结果、数据集漂移、硬门禁失败或新增回归时 fail closed。

验收：同一 fixture 可重复回放；收益和回归均能定位到证据，不能用一次通过替代收益证明。

### R8-05：人工批准、激活与回滚

- 批准绑定 actor、reason、候选哈希、数据身份和验证结果。
- 激活前重新验证版本与内容哈希；保存此前 active pointer。
- 回滚只恢复精确旧指针；出现并发变更时拒绝覆盖。

验收：未批准不能运行；批准后下一轮真实加载；回滚后恢复原状态，项目源码字节不变。

### R8-06：受控 Skill 导出

- 将已验证经验显式导出为项目内 Skill 草稿，包含适用条件、来源、限制、验证和回滚说明。
- 导出不自动安装，不覆盖全局 Skill，不赋予源码写入或凭据访问能力。

验收：导出内容可审计、可重复生成；未验证或已撤销经验不能导出为可用 Skill。

### R8-07：页面诊断与操作入口

- 展示活跃经验、待审核候选、来源问题、适用检查、收益、回归和最近使用结果。
- 提供查看证据、批准、拒绝、停用和回滚入口；危险操作需要明确理由。
- 首页只显示决策指标，详细证据按需展开。

验收：用户能从一个失败定位到候选、验证结果和最终状态；页面不暴露未脱敏日志或凭据。

### R8-08：最小真实闭环验收

- 选择一个小型固定 fixture，制造可重复失败并运行 baseline。
- 生成候选，执行 regression/holdout，人工批准，在下一轮确认加载，再执行回滚。
- 核对源码未变、manifest 完整、谱系连续、日志脱敏和无模型降级路径。

验收：闭环中的每一步都有真实 artifact 和明确退出状态；负面候选必须有拒绝证据。

### R8-09：文档与阶段审计

- 更新使用指南、Schema、安全边界、操作手册和执行记录。
- 回答本地优先、数据暴露、根目录、状态准确性、恢复审计和个人维护成本八项一致性问题。
- 列出未覆盖范围和回滚方式。

验收：只有 R8-01 至 R8-09 的必需项全部有当前基线证据时，才能标记 R8 最小闭环完成。

## 暂缓任务

- 多小时收益长跑和大规模候选比较。
- 多模型、多 provider 和多宿主矩阵。
- 自动批准、自动激活和常驻进化循环。
- 自动修改项目源码或生成可直接应用的补丁。
- 跨项目经验市场、远端同步和云端观测。
- macOS、原生 Ubuntu；随开源 CI 补验，不阻塞首个 R8 fixture。
