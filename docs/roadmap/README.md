## 推荐迭代顺序

1. **可信底座**：F-01/F-02 与 Q-01/Q-02/Q-03 小步修复。已知错误不应等待整个 RFC 重构完成。
2. **可维护边界**：F-03 → F-04/F-05，Q-04。机械迁移与有意行为变化分开提交。
3. **有用但不自治**：S-01、S-03、S-04；无模型/无宿主仍能使用基础评估。MCP 不是 Skill 的强制依赖。
4. **受控写入**：H-01 → H-02 → H-03，先人工批准，验证边界后才允许有限自动应用。
5. **持续运行**：L-01/L-02；L-03 的外部观测集成为可选项，不阻塞本地闭环。
