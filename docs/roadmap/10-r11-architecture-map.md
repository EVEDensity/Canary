# R11：可交互项目架构地图

R11 在 R10 封存结构上加入首页入口与同页地图。具体操作见[架构地图指南](../guides/architecture-map.md)，验证结果见 [R11 证据](../evidence/r11-execution.md)。

| 需求           | 实现                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 二维与三维分层 | 默认二维层级与依赖连线；CSS 透视三维分层、倾角控制和二维回退         |
| 逐层展开       | 项目、应用/包、目录、文件、JS/TS 类与函数；树、面包屑、双击进入      |
| 查找与过滤     | 名称/路径/符号搜索、关系过滤、一跳上下游、节点和连线数量上限         |
| 节点详情       | 结构职责、源码位置、Git 变更、上下游、未知关系、可靠关联的检查和覆盖 |
| 历史与访问     | 封存运行读取、哈希匹配的源码片段、按运行保存界面状态、键盘导航       |

边界：静态边不等于实际运行调用；无覆盖文件时不猜测检查关联；非 JS/TS 语言本阶段只在页面展示目录/文件。大项目默认绘制数量受限，但树与搜索仍可访问其余节点。R11 不改变 R10 的扫描上限和语言适配范围。
