# 图标与视觉细节精修

保持用户确认的暖白、石墨与珊瑚橙方向。本次参考用户指定的 [Lucide](https://lucide.dev/icons/) 与 [LobeHub Icons](https://lobehub.com/zh/icons)。Lucide 用于通用操作；LobeHub 提供 AI 品牌标识，当前运行缺少可靠的品牌关联字段，因此未添加推测性的模型品牌徽标。

## 实现

- 从 `lucide-static@1.47.0` 选择 SVG，生成本地 sprite；导航、操作、运行状态、图表标题和抽屉关闭按钮使用统一的 24 单位网格与 1.7 描边。
- Canary 品牌角标采用 Lucide bird。品牌链接具有明确的可访问名称，装饰图标对读屏隐藏；窄栏导航保留文本语义与 title 提示。
- 去除章节编号式标题，换成淡彩底色的语义图标。调整卡片边缘、轻阴影、条形渐变、图表渐隐填色和状态图形。
- 通过与异常使用不同状态图形及底色，未改变真实数据或校验逻辑。按钮提供轻量按压与悬停反馈，仍尊重 reduced-motion。
- SVG 无远端运行时依赖；版权及许可随 HTML 和发布文件保留于 `apps/web/LUCIDE-LICENSE.txt`。

## 验证

Web 构建和 20 项 Web 测试通过，lint 通过。桌面浏览器实际统计 39 个 SVG 引用，全部能解析到对应 symbol，页面无错误提示。继续保留原有指标切换、图表键盘操作、检查抽屉及 Escape 关闭能力。

正式端口浏览器验证失败运行显示 1 项待处理和 warning 图形状态，抽屉支持 Escape 关闭。390 像素视口文档宽度为 375，SVG 缺失引用为 0，品牌链接可访问名称为 Canary 首页。
