# 数据仪表盘改版

## 用户任务

打开首页判断运行状态、发现波动、定位耗时与覆盖缺口，再从侧栏进入执行日志、用例或证据。首页取消介绍性标语，以图表为主；运行历史从侧栏主内容迁移到独立视图，顶部提供运行选择器。

## 实现

- 四张首页图表：同类型运行的计划项通过率趋势、当前运行结果环图、最长 8 项耗时、四类代码覆盖率。
- 历史窗口支持最近 12、24、50 次已结束运行；趋势点支持鼠标及键盘选择。重试标记 R，不假设不同运行计划可直接等价比较。
- 固定侧栏：数据总览、检查与日志、覆盖率分析、用例与轨迹、证据与比较、改进建议、运行历史。
- 深蓝界面、紧凑指标卡、双列图表；窄屏为横向导航和单列图表。沿用已有脱敏、完整性校验及写操作授权。
