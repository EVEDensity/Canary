# 总览信息精简与历史记录整理

总览先显示运行身份、核心指标与图表。删除品牌副标题和重复指标解释；图表读法按需展开。通过时隐藏问题清单，异常清单位于图表之后，右侧保留异常入口。修正标题继承图标网格后被挤成竖排的问题。滚动条使用 thin 和 6px WebKit 样式，实际宽度由浏览器实现决定。

历史按本地日期分组，显示秒级时间、已记录检查/用例名称、状态、通过数与耗时。项目记录下折叠关联 Agent 子运行；重试、重放保留来源入口。支持原始检查 ID、中文名称、日期、时间与运行 ID 搜索。历史页隐藏当前运行的指标，避免混淆。运行选择器按日期分组，选项补充时间与检测类型。

## 验证

- Web build、20 项 Web 测试及 lint 通过；生成的页面脚本语法检查通过。
- 摘要接口测试检查项目名称列表与 Agent 父子关联，保持不返回完整 trace。
- 浏览器验证真实项目记录展开 Agent 子运行、workspace.test 搜索，以及历史页隐藏无关指标。
- 1440px 桌面首屏图表与 390px 手机布局检查；手机内容宽度与可视宽度均为 380px，无横向溢出。

历史摘要仍限最近 100 条；父记录不在窗口内时不声称 Agent 是独立运行。摘要来自记录索引，选中运行后继续校验 artifact 完整性。检查内容仅表示已记录项目，不推断未完成步骤。
